# Asking a person to do something by hand

1. **Check first** whether it can be done without a person. Often it can.
2. If not, give **the exact URL for every step** (the form itself, not "Settings → Secrets"). A link either works or visibly doesn't; menu paths go stale silently.
3. Say **what the step is for** and **what is safe** ("resetting this breaks nothing; the app uses API keys").
4. Repository settings, secrets and anything that costs money are Jonathan's -- address him.
5. Write it once, complete, so nobody has to ask for the links again.
